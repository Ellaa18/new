# For Ind 💕

A heartwarming interactive web experience — catch falling hearts in a basket for Ind.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in your terminal (usually `http://localhost:5173`).

## How it works

1. Hearts fall from the sky
2. Drag the basket left and right (touch or mouse)
3. Catch **15 hearts** to fill your basket
4. The message changes to *"You caught all my heart — get into it"*
5. Tap **Get on the heart** for the final surprise

Made with React, Tailwind CSS, and love.
